# Портативный накопитель

Портативный накопитель позволяет носить энергию в инвентаре. Чтобы зарядить или разрядить его, щёлкните правой кнопкой мыши по любому блоку-накопителю.

<Recipe id="modern_industrialization:electric_age/battery/portable_storage_unit_asbl" />

Сам по себе портативный накопитель не хранит энергию. Установите в него батареи: щёлкните правой кнопкой мыши батареей по накопителю или накопителем по батарее. Чем выше уровень батарей, тем больше прибавка к ёмкости. Батарею можно вынуть, щёлкнув правой кнопкой мыши по пустой ячейке, но избыток энергии пропадёт.
